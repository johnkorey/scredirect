Description

Microsoft Excel, the world's leading spreadsheet app, makes it easy to organize, analyze, and visualize your data from anywhere.

  • Format cells with fonts, colors, and conditional formatting

Microsoft Excel, the world's leading spreadsheet app, makes it easy to organize, analyze, and visualize your data from anywhere.

BUILD POWERFUL SPREADSHEETS

  • Start from a blank workbook or a ready-made template
  • Format cells with fonts, colors, and conditional formatting
  • Enter data fast with AutoFill and Flash Fill
  • Keep workbooks organized with multiple sheets

ANALYZE DATA WITH FORMULAS

  • Choose from hundreds of built-in functions
  • Find values instantly with XLOOKUP
  • Build nested logic with IF, IFS, and LET
  • Get formula suggestions as you type

VISUALIZE WITH CHARTS

  • Turn numbers into charts in a few clicks
  • Pick from column, line, pie, and map charts
  • Get chart recommendations for your data
  • Customize colors, labels, and legends

SUMMARIZE WITH PIVOTTABLES

  • Summarize thousands of rows in seconds
  • Group, filter, and drill into your data
  • Refresh results when source data changes
  • Visualize summaries with PivotCharts

COLLABORATE IN REAL TIME

  • Co-author workbooks with others at the same time
  • Comment and @mention teammates in cells
  • Share with a link and control who can edit
  • Review changes with version history

WORK WHERE YOU ARE

  • Access workbooks on desktop, web, and mobile
  • Keep files in sync with OneDrive cloud storage

DO MORE WITH MICROSOFT 365 COPILOT

  • Generate formulas from plain language
  • Summarize trends and outliers instantly
  • Build tables and charts from a prompt
  • Ask questions about your data

Copilot features may require an eligible Microsoft 365 subscription. Details: Microsoft Excel help & learning
