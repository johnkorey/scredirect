Description

Microsoft OneDrive, the personal cloud storage built into Windows, makes it easy to store, sync, back up, and share your files from anywhere.

STORE FILES IN THE CLOUD

  • Save documents, photos, and videos in one place
  • Get 5 GB of free cloud storage
  • Free up disk space with Files On-Demand
  • Open files right from File Explorer

Microsoft OneDrive, the personal cloud storage built into Windows, makes it easy to store, sync, back up, and share your files from anywhere.

STORE FILES IN THE CLOUD

  • Save documents, photos, and videos in one place
  • Get 5 GB of free cloud storage
  • Free up disk space with Files On-Demand
  • Open files right from File Explorer

SYNC ACROSS ALL YOUR DEVICES

  • Keep files identical on PC, web, and mobile
  • Changes save and sync automatically
  • Work offline and sync when you reconnect
  • Pick up where you left off on any device

BACK UP IMPORTANT FOLDERS

  • Automatically back up Desktop, Documents, and Pictures
  • Restore files if your PC is lost or damaged
  • Recover earlier versions of any file
  • Get protection against ransomware with file restore

SHARE FILES AND FOLDERS

  • Share with a link, no account required for viewing
  • Set passwords and expiration dates on links
  • Control who can view or edit
  • See when shared files are opened

WORK WITH YOUR FAVORITE APPS

  • Open and save directly from Word, Excel, and PowerPoint
  • Co-author Office documents stored in OneDrive
  • Edit photos and files right in the browser
  • Scan documents with the mobile app

KEEP FILES SAFE

  • Store sensitive files in Personal Vault with extra verification
  • Trust encryption in transit and at rest

WORK WHERE YOU ARE

  • Access files on Windows, web, iOS, and Android
  • Keep everything in sync automatically
